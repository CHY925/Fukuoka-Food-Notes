# 福岡美食筆記

繁體中文的福岡料理靜態網站，使用 HTML 與共用 CSS，無建置工具、外部字型、JavaScript、後端或追蹤程式。

## 本地瀏覽
解壓縮後進入 Fukuoka-Food-Notes，直接雙擊 index.html。保留完整資料夾結構，圖片及分類連結即可運作。

## 檔案
- Fukuoka-Food-Notes-Rules.md：最新版專案規則（附件原文保留）。
- AGENTS.md：導向最新版規則的 Agent 入口。
- index.html：首頁。
- categories/motsunabe.html、categories/mizutaki.html：料理分類頁。
- assets/css/style.css：全站共用響應式樣式。
- assets/images/：本地圖片與 SOURCES.md 授權紀錄。
- image-credits.html：公開圖片授權資訊。
- sources.md：餐廳與料理資料來源及待確認事項。
- verification.md：檢查紀錄。

## 維護
新增分類時複製既有分類頁，修改資料及路徑，同步新增首頁入口與圖片來源；新增餐廳沿用 restaurant 區塊。發布時需保留圖片署名與授權資訊。
